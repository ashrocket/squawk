The first screen of the Squawk landing page, with its header, headline, action row and channel illustration.

Use this pattern for the top of any Squawk landing page. Keep the headline, the one-line promise and the single primary action.

- Consumer supplies: the headline, the sub-line, the primary action text and link, and the footnote.
- Use one primary action (Get Squawk). Keep the text link as a secondary action.
- Do not add a second primary button, a gradient or a shadow to the hero.
- Do not change the headline span colour. It is the accent (`--orange`).
- The illustration in this preview is a token-only reduction of the real figure. The real case uses literal gradients (site/public/styles.css:201), which this system does not formalize.
