# Squawk logo files

Both files are copies made with `cp`. Neither file was redrawn.

- `radio.svg`: the Squawk mark, copied from `site/public/radio.svg`. A 48-unit square SVG with an orange body (#dc492c), an ink antenna and dial (#242822) and a paper display (#eeede5). Used as the favicon and at 35px in the header. Minimum size: not defined in code.
- `icon.png`: a 1024 by 1024 px raster app icon, copied from `site/public/icon.png`. It has no ink colour: it is a full-colour raster, not a one-ink mark. The landing page does not reference it. Minimum size: 1024 by 1024 px, the size of the file. The code defines no smaller size.

The wordmark is set type, not a file. See `../../README.md`, section "Logo and wordmark".
